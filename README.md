## 目录结构

每个工程都是同一套模板，结构一致：

```
3-1LED闪烁/
├── Project.uvprojx     ← Keil5 工程文件，双击打开
├── User/               ← main.c、中断服务函数
├── Hardware/           ← 自己写的外设驱动（LED / Key / OLED / Serial ...）
├── System/             ← 延时、定时器等系统级封装
├── Library/            ← STM32 标准外设库
└── Start/              ← 启动文件、CMSIS
```

看代码重点看 **`User/` 和 `Hardware/`** 两个目录，其余是库和启动文件。

**每个工程目录下都有一份 `README.md`**，写清了这个工程做什么、外设接在哪个引脚、下载后能看到什么现象、关键代码是哪几行，以及当时踩过的坑。手机上一翻就知道怎么接线。

## 怎么用

1. 装好 **Keil MDK5** 和 **STM32F1xx 器件支持包**
2. 打开对应工程目录下的 `Project.uvprojx`
3. F7 编译，F8 下载（ST-Link / DAP-Link）

> 仓库里不含 `Objects/`、`Listings/` 等编译中间文件 —— 那些是每次 Build 自动生成的，
> 体积大且和自己机器上的路径绑定，上传上去反而没用。第一次 Build 会自动重建。

## 硬件

- 主控：STM32F103C8T6 最小系统板（Blue Pill）
- 下载器：ST-Link V2
- 外设：OLED（SSD1306，软件 I2C）、旋转编码器、对射式红外传感器、SG90 舵机、
  直流电机 + 驱动、MPU6050、W25Q64、USB 转 TTL 模块等
