# 3-5 光敏传感器控制蜂鸣器

> **章节** 3-5 ｜ **芯片** STM32F103C8T6（72 MHz）｜ **库** STM32 标准外设库 ｜ **IDE** Keil MDK 5
> [← 返回总目录](../README.md)

## 这个工程做什么

数字量光敏模块（DO 输出）+ 有源蜂鸣器：环境变暗时蜂鸣器报警。
光敏模块内部有比较器，遮光/见光时 DO 翻转，单片机只需要读一个数字脚。

## 硬件连接

| 外设 | 引脚 | 说明 |
| --- | --- | --- |
| 光敏模块 DO | PB13 | 上拉输入（IPU），模块输出数字量 |
| 光敏模块 VCC/GND | 3V3 / GND | 必须共地 |
| 有源蜂鸣器 | PB12 | 低电平触发 |

## 现象

用手遮住光敏电阻 → 蜂鸣器响；松手见光 → 停止。

## 关键代码

```c
if (LightSensor_Get() == 1)		// 模块 DO 输出高 → 判定为暗
	Buzzer_ON();
else
	Buzzer_Off();
```

## 备注

**踩过的坑**：`LightSensor.c` 里 `GPIO_Init` 配的是 **GPIOB**，但 `LightSensor_Get()` 读的却是 **GPIOA** —— 而 GPIOA 时钟根本没开，读回来恒为 0，光敏完全失效。同文件还有一句 `GPIO_SetBits(GPIOA, Pin_13)`，`Buzzer.c` 里也有 `GPIO_SetBits(GPIOA, Pin_12)`，都是端口写错。

**极性**：不同模块的 DO 极性可能相反。如果烧进去是"见光才响"，把判断改成 `== 0` 即可。
**抖动**：主循环里死等，没有迟滞，临界亮度下会"咔咔"抖着响 —— 想要稳定得加回差判断。
