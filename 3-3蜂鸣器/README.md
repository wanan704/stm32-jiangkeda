# 3-3 蜂鸣器

> **章节** 3-3 ｜ **芯片** STM32F103C8T6（72 MHz）｜ **库** STM32 标准外设库 ｜ **IDE** Keil MDK 5
> [← 返回总目录](../README.md)

## 这个工程做什么

GPIO 驱动有源蜂鸣器：PB12 输出低电平时三极管导通，蜂鸣器响。
代码在 `ResetBits`（响）和 `SetBits`（停）之间来回切换。

## 硬件连接

| 外设 | 引脚 | 说明 |
| --- | --- | --- |
| 有源蜂鸣器 | PB12 | 低电平触发（经三极管驱动），高电平停止 |

## 现象

响 500 ms、停 500 ms，循环发出"滴 — 滴 —"声。

## 关键代码

```c
GPIO_ResetBits(GPIOB, GPIO_Pin_12);	// 低电平 → 响
Delay_ms(500);
GPIO_SetBits(GPIOB, GPIO_Pin_12);	// 高电平 → 停
Delay_ms(500);
```

## 备注

这套写法只对**有源蜂鸣器**（内部自带振荡电路）有效。无源蜂鸣器给直流不会响，必须用 PWM 送 2~4 kHz 方波 —— 那是 6-3 之后 PWM 章节的内容。
