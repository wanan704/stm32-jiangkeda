# 9-1 串口发送

> **章节** 9-1 ｜ **芯片** STM32F103C8T6（72 MHz）｜ **库** STM32 标准外设库 ｜ **IDE** Keil MDK 5
> [← 返回总目录](../README.md)

## 这个工程做什么

USART1 初始化成 9600-8-N-1，只开发送。演示发字节、数组、字符串、数字、十六进制、二进制、浮点。

## 硬件连接

| 外设 | 引脚 | 说明 |
| --- | --- | --- |
| PA9 (TX) | → 模块 RXD | 复用推挽输出，**交叉连接** |
| PA10 (RX) | ← 模块 TXD | 本工程只发不收，可以不接 |
| GND | → 模块 GND | 必须共地，否则收不到 |

## 现象

串口助手（9600、8N1）里能看到 Hello World、数字、十六进制、二进制、浮点等一串内容。

## 关键代码

```c
USART_SendData(USART1, Byte);
while (USART_GetFlagStatus(USART1, USART_FLAG_TXE) == RESET);	// 等发送完成
```

## 备注

**发送可以死等**：发是自己主动发起的，等几十微秒无所谓。接收就不行 —— 见 9-2。

USB 转串口模块上的跳线帽是**二选一**：帽插 VCC–3V3 输出 3.3V，插 5V–VCC 输出 5V。选 3V3，TXD 的高电平才会是 3.3V。
