# 4-1 OLED 显示屏

> **章节** 4-1 ｜ **芯片** STM32F103C8T6（72 MHz）｜ **库** STM32 标准外设库 ｜ **IDE** Keil MDK 5
> [← 返回总目录](../README.md)

## 这个工程做什么

驱动 0.96 寸 SSD1306 OLED（128×64），用**软件 I2C** 模拟时序。
提供字符、数字、十六进制、二进制、浮点、中文、图片七套显示函数。

## 硬件连接

| 外设 | 引脚 | 说明 |
| --- | --- | --- |
| OLED SCL | PB8 | 开漏输出，模块板载 4.7k 上拉 |
| OLED SDA | PB9 | 开漏输出，读的时候切输入 |
| OLED VCC/GND | 3V3 / GND | 3.3V 供电，务必共地 |

## 现象

屏幕点亮，依次显示字符、数字、十六进制、二进制、浮点、中文和一张图片。

## 关键代码

```c
OLED_Init();
OLED_ShowString(1, 1, "Hello World!");
OLED_ShowNum(2, 1, 12345, 5);
OLED_ShowHexNum(3, 1, 0xA5A5, 4);
OLED_ShowChinese(4, 1, 0);
```

## 备注

**"有时亮有时不亮"的常见原因**（这份驱动三个工程完全一样，不是版本问题）：

1. `OLED_Init()` 只在上电时跑一次，且不读 ACK、不重试 —— 上电瞬间没初始化成功就**永久黑屏**，只能重新上电；
2. 初始化前的延时是纯空循环，不是准数，主频/优化等级变了就可能不够；
3. 杜邦线/面包板接触不良，晃一下线就亮灭；
4. ST-Link 的 3.3V 带载能力有限，OLED 全屏点亮瞬时电流大，会把它拖复位。

先分清是"每次上电随机"还是"跑着跑着突然灭"，前者查接触和上电延时，后者查电源和总线。
