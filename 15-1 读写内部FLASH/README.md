# 15-1 读写内部 FLASH

> **章节** 15-1 ｜ **芯片** STM32F103C8T6（72 MHz）｜ **库** STM32 标准外设库 ｜ **IDE** Keil MDK 5
> [← 返回总目录](../README.md)

## 这个工程做什么

把参数存进 STM32 内部 Flash 的最后一页，实现掉电不丢失。
`Store.c` 封装了"上电校验标志 → 加载数据 / 保存 → 擦除"的逻辑，`main` 用两个按键操作。

## 硬件连接

| 外设 | 引脚 | 说明 |
| --- | --- | --- |
| 按键 K1 | PB1 | 数据 +1/+2/+3/+4 并保存 |
| 按键 K2 | PB11 | 全部清 0 |
| OLED | PB8 / PB9 | 显示 Flag 和 4 个数据 |

## 现象

按 K1 数据变化并立即保存，复位/断电再上电数据仍在；按 K2 清零，Flag 变 0。

## 关键代码

```c
FLASH_Unlock();
FLASH_ErasePage(0x0800FC00);			// 先擦整页
for (i = 0; i < 5; i++)
	FLASH_ProgramHalfWord(0x0800FC00 + i * 2, Store_Data[i]);
FLASH_Lock();
```

## 备注

**Flash 只能"先擦后写"**，而且最小擦除单位是一页（C8T6 是 1 KB）。擦完变 `0xFF`，再往里面写半字。

**寿命有限**（约 1 万次擦写），别在循环里频繁保存 —— 要么加按键触发，要么做磨损均衡。

`Store_Data[0]` 存的 `0xA5A5` 是"数据有效"标志：第一次上电读到全 `0xFF` 就初始化默认值，避免把随机数据当参数用。
