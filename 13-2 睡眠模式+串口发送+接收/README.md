# 13-2 睡眠模式 + 串口收发

> **章节** 13-2 ｜ **芯片** STM32F103C8T6（72 MHz）｜ **库** STM32 标准外设库 ｜ **IDE** Keil MDK 5
> [← 返回总目录](../README.md)

## 这个工程做什么

CPU 执行 `__WFI()` 进入睡眠模式（只关 CPU 时钟，外设照常跑），串口收到数据产生中断把它叫醒。

## 硬件连接

| 外设 | 引脚 | 说明 |
| --- | --- | --- |
| PA9 / PA10 | TX / RX | 9600-8-N-1，接 USB 转串口模块 |

## 现象

主循环先闪 `Running`，然后进睡眠；串口发一个字节，程序被唤醒、回传并显示，然后再次睡眠。

## 关键代码

```c
__WFI();	// 等中断，CPU 停机，外设仍在运行
```

## 备注

**睡眠模式最省事**：任何中断都能唤醒，醒来接着执行 `__WFI()` 下一条，不用重新初始化时钟。

对比 13-3 的停止模式（醒来要 `SystemInit()`）和 13-4 的待机模式（醒来等于复位），睡眠是最轻的一档。

用电流表能看到：睡眠时电流从几十 mA 掉到十几 mA。
