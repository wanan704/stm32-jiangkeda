# 3-2 LED 流水灯

> **章节** 3-2 ｜ **芯片** STM32F103C8T6（72 MHz）｜ **库** STM32 标准外设库 ｜ **IDE** Keil MDK 5
> [← 返回总目录](../README.md)

## 这个工程做什么

用 `GPIO_Write()` 一次写整个 ODR，让"低电平的那一位"从 PA0 一路移到 PA15，做出流水效果。
核心是 `~0x0001`、`~0x0002` … `~0x8000` 这一串按位取反的掩码。

## 硬件连接

| 外设 | 引脚 | 说明 |
| --- | --- | --- |
| LED ×16 | PA0 ~ PA15 | 阳极接 3V3、阴极经电阻接引脚 —— **低电平点亮** |

## 现象

一个亮点从 PA0 顺序流到 PA15，每步 500 ms，然后回到 PA0。

## 关键代码

```c
uint16_t pin = 0x0001;
while (1)
{
	GPIO_Write(GPIOA, ~pin);	// 只有 pin 对应的那一位是 0，其余全 1
	Delay_ms(500);
	pin <<= 1;
	if (pin == 0x0000) pin = 0x0001;
}
```

## 备注

**这套代码只适用于"低电平点亮"**。任意时刻 ODR 里只有 1 位是 0、其余 15 位是 1，所以：

- 低电平点亮的灯 → 只有 1 个亮，流水正常；
- 高电平点亮的灯（阴极接地、阳极接引脚）→ 15 步都在亮，只有轮到自己那一步灭，看起来就是**常亮 + 反向闪**。

另外 `GPIO_InitStructure.GPIO_Pin = GPIO_Pin_All` 会把 **PA13/PA14（SWDIO/SWCLK）** 也配成输出，可能把 SWD 下载口打掉，下次烧录要按住 RESET。建议只初始化实际用到的引脚。
